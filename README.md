# 🕌 دليل دمشق وريف دمشق

**دليلك السريع للخدمات الطبية والحكومية في دمشق وريف دمشق** — أسماء، عناوين، أرقام هواتف، ودوام، بواجهة عربية واضحة وسريعة.

🔗 **الموقع المباشر:** https://ypyv.github.io/

---

## ✨ ما يقدمه الموقع

- 🏥 **دليل طبي** — مشافي، مراكز صحية، مخابر، ومراكز تصوير طبي.
- 🏛️ **دليل حكومي** — وزارات، مديريات، ومؤسسات خدمية.
- 🔍 بحث فوري بالاسم أو المنطقة أو الهاتف، مع فلاتر حسب النوع والتصنيف والمحافظة وحالة التوثيق.
- 🟢🟡 حالة توثيق واضحة لكل جهة (موثقة / تحتاج تحديث) — بدون اختلاق معلومات ناقصة.
- 📍 روابط خرائط مباشرة و☎ اتصال بضغطة واحدة.
- 🚑 قسم أرقام طوارئ ثابت (إسعاف، دفاع مدني، شرطة...).
- 📲 يعمل كتطبيق قابل للتثبيت على الهاتف (PWA)، ويشتغل حتى بدون إنترنت بعد أول زيارة.

## 🛠️ التقنية

موقع ثابت بالكامل — HTML / CSS / JavaScript فقط، بدون أي إطار عمل (framework)، ليبقى خفيفاً وسريعاً ومناسباً لـ GitHub Pages.

## 📂 البيانات

كل بيانات الجهات موجودة بملف [`data/directory.json`](data/directory.json) بصيغة JSON بسيطة يمكن تعديلها مباشرة.

## ⚑ لاحظت معلومة خاطئة؟

تواصل معنا مباشرة عبر [واتساب](https://wa.me/?text=لاحظت%20معلومة%20خاطئة%20بدليل%20دمشق%20وريف%20دمشق:%20) وسنقوم بمراجعتها.

# 🕌 Dalil Damascus & Rif Dimashq *(EN)*

**A fast, bilingual-friendly directory of medical and government services in Damascus and Rif Dimashq, Syria** — names, addresses, phone numbers, and hours, in a clear Arabic interface.

🔗 **Live site:** https://ypyv.github.io/

## ✨ Features

- 🏥 **Medical directory** — hospitals, clinics, labs, and imaging centers.
- 🏛️ **Government directory** — ministries, directorates, and public services.
- 🔍 Instant search by name, area, or phone number, with filters for type, category, governorate, and verification status.
- 🟢🟡 Clear verification status per entry (verified / needs update) — no fabricated data.
- 📍 Direct map links and one-tap ☎ calling.
- 🚑 A fixed emergency-numbers section (ambulance, civil defense, police...).
- 📲 Installable as a PWA, with basic offline support after the first visit.

## 🛠️ Tech stack

Fully static — plain HTML / CSS / JavaScript, no framework, kept lightweight and fast for GitHub Pages.

## 📂 Data

All entries live in [`data/directory.json`](data/directory.json) as plain, easily editable JSON.
